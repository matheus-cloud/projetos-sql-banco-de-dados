## 📋 Sobre o Repositório
Este repositório consolida as atividades práticas desenvolvidas nos módulos de **SQL e Bancos de Dados**, abrangendo desde a instalação e configuração de SGBDs até consultas avançadas, manipulação de dados (DML), definição de estruturas (DDL), agregações e junção de múltiplas tabelas.

---

## 🛠️ Módulos e Projetos Práticos

### 1. Fundamentos, Instalação e SGBD
* **Descrição:** Configuração de ambiente de banco de dados relacional (MySQL), verificação de comandos básicos e estruturação inicial no terminal e no MySQL Workbench[cite: 16].

### 2. Linguagem de Definição de Dados (DDL) & Consultas em Múltiplas Tabelas
* **Descrição:** Criação de estrutura de banco de dados (como o sistema de um restaurante), modelagem de tabelas relacionais com chaves primárias e estrangeiras, inserção de dados e consultas complexas cruzando múltiplas tabelas[cite: 14, 17, 18, 22].

### 3. Filtros, Condicionais e Linguagem de Manipulação de Dados (DML)
* **Descrição:** Aplicação de filtros avançados, tratamentos condicionais, inserção, atualização e persistência de dados em tabelas relacionais[cite: 15, 20].

### 4. Agregações e Linguagem de Consulta de Dados (DQL)
* **Descrição:** Utilização de funções de agregação, agrupamentos e consultas estruturadas para extração de insights e relatórios analíticos[cite: 21, 23].

---

## 📚 Conceitos Teóricos e Comparativos
* **Bancos de Dados Relacionais (SQL):** Foco em integridade transacional (ACID), esquemas estruturados e consistência para sistemas críticos[cite: 19].
* **Bancos de Dados Não Relacionais (NoSQL):** Visão geral sobre flexibilidade para dados não estruturados, escalabilidade horizontal e subtipos (Chave-Valor, Documentos, Colunas e Grafos)[cite: 19].
